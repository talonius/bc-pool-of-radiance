# Changelog

This is the player-facing summary of what has changed in the Pool of Radiance port. If you want implementation details, issue numbers, or commit references, see [Detailed changes](detailed-changes.md).

## What has changed since the October 2026 update

This update is a broad one: it adds an easier setup process, smarter inventory handling, more useful combat information, and a long list of fixes. Existing games and characters remain compatible.

### New features

- **Auto Join keeps stacks together.** When you buy, take, or trade arrows, darts, and other stackable items, they now join a matching stack you already carry. That saves one of your 16 item slots and keeps a readied quiver readied. Auto Join is on by default; you can turn it off from the Settings screen or POOLCFG. To make room, Settings now has separate Game and Sound pages, System has moved to Y, and POOLCFG has gained Sound Settings.
- **Rest memorizes your casters' usual spells again.** Once a character has confirmed a set of spells in Memorize, Rest in camp brings back whatever was cast since, as Pools of Darkness does, without opening Memorize for each caster. A character with spells already picked in Memorize keeps that set. Auto Memorize, on by default on the new Camp page of the Settings screen (and Camp Settings in POOLCFG), turns this off. The Settings screen's bottom line drops its "Settings:" prompt to make room for Camp.
- **Fix knows about level drain and mummy rot, and can use your items.** A drained cleric who can no longer cast a cure is now named ("is level drained and can't cast Cure Disease") instead of Fix resting for nothing, and Fix no longer spends healing on a character with mummy rot that no one can cure. Four new settings under Fix on the Camp page, all off by default, let Fix use scrolls (Restoration first, so a restored cleric's spells count in the same Fix, then Cure Disease, Cure Blindness, Remove Curse and Cure Light Wounds), Potions of Healing and Keoghtom's Ointment, a paladin's weekly cure, and a paladin's laying on of hands for whatever the clerics' spells leave. Fix then lists who used what, and on whom, waiting for a key when the list fills the window.
- **Silver shields can turn aside a petrifying gaze.** A character with one readied is safe from the gaze of a basilisk or medusa.
- **The DOS release now includes a setup program, `POOLCFG.EXE`.** Run it from the game folder to choose the video mode, sound device, introduction, in-game settings, and Pool of Radiance's data and save folders. Any folder you enter must already exist; otherwise, POOLCFG says "Please verify the directory exists." and creates nothing. It also writes nothing until you choose Save and Exit or press F10. If POOL.CFG is missing or damaged, START opens POOLCFG before launching the game with your choices. A damaged file first produces the message "POOL.CFG was damaged, unreadable, or unparseable. Please reconfigure the game." Leaving without saving returns you to DOS. Lower-case letters in POOL.CFG are accepted now too.
- **Linux, Windows, and macOS include `poolcfg` too.** You will find it beside `poolrad`; run it from a terminal (Terminal on a Mac), and it locates the game folder the same way the game does. It offers the same pages as `POOLCFG.EXE`, with explanations tailored to the native release. The picture is always VGA, and sound always uses the game's digital music and effects, regardless of the DOS hardware choices. Turn off Music and Sound if you want silence. You can point the game at any existing data or save folder. If POOL.CFG is missing or unreadable, the game uses sensible defaults—digital sound, the full introduction, and saves in SAVE—and tells you in the terminal that `poolcfg` is available. It no longer asks for the startup disk, and it can locate its own folder from the game data before POOL.CFG exists. The game never opens `poolcfg` for you.
- **The native releases can find an installed GOG, Steam, or Heroic copy on their own.** The port no longer needs to live inside the original game folder. It checks beside the program, the last folder used, Steam's libraries, GOG's install folder (inside GOG's Pool of Radiance app on a Mac), and Heroic's folder. If it finds one copy, it remembers and uses it; if it finds several, it asks you to choose; if it finds none, it opens a folder picker or asks you to enter the path. Use `--choose-data-folder` to choose again, or `--data-folder PATH` to supply one directly. Store folders and GOG's Mac app are left untouched. Saves, settings, the Bestiary, and combined data files go into your own application-data folder (`~/Library/Application Support/Pool of Radiance` on macOS, `%APPDATA%\Pool of Radiance` on Windows, and `~/.local/share/pool-of-radiance` on Linux). If you unpack the port into a writable game folder, it continues to keep everything there as before. The release looks for its title picture and Sound Blaster effects beside the program first, then in the game folder. The macOS archive includes a README.TXT with the same guidance.
- **Stojanow Gate feels reclaimed after you take it.** New Phlan's guards cheer as you approach or pass through the gate, once per visit, and the two guard rooms become makeshift barracks for New Phlan's troops. None of these messages waits for Return.
- **Dirten helps restore the Temple of Bane.** If he is with you when the temple is freed, he stays behind as before. If he fell in the fight, the temple guards arrive and a cleric rushes to help him. Two weeks of game time later, Dirten welcomes you at the old altar and offers the temple's healing at a ten percent discount; until then, you hear that rebuilding is underway. In an older save where Dirten joined and the temple is already free, the two-week wait begins on your first visit to the altar after updating.
- **Area spells show who they will catch before you cast.** As you move the targeting cursor, the line above the menu names the spell and counts enemies in yellow and allies in cyan: for example, "FIREBALL: 3 ENEMIES, 1 ALLY" or "No targets". Fireball, Lightning Bolt and its bounce, Stinking Cloud, Sleep, and the other area spells all work this way, even when a creature is just off-screen. Sleep also shows its maximum when it cannot affect everyone. The preview never reveals immunities; immune creatures still count like anyone else.
- **Human characters can dual-class at a training hall, as in Curse of the Azure Bonds.** Choose Dual Class from the party menu to see the available classes, their prime-requisite requirements, the character's scores, and any reason the selected class is unavailable. Changing class costs 2,500 gp. The character keeps the old levels but begins the new class at level 1 with no experience. The old class's abilities remain unavailable, and the character gains no hit points, until the new class passes the old class's level; after that, the character uses the better abilities of both and trains only in the new class. A character can change class only once and must restore any drained level first.
- **The Journal lists what you have found.** A new game starts with an empty Journal ("Your journal is empty."). An entry joins it when the game tells you to put it in your journal, a tavern tale when you overhear it in New Phlan's tavern, and the proclamations when you read them on City Hall's walls. To read the whole book as before, set Journal to ALL on the Settings screen's Game page (or in POOLCFG); FOUND is the default. A game saved before this update counts everything as found, so its Journal is as full as it was. Finding one of the Journal's maps also opens the Area view and the coordinates where the game hid them: the kobolds' map of the Textile House (entry 10), Tyrmor's map of the pyramid maze on Sorcerer's Island (26), the NE and NW castle mazes of Valjevo Castle (29 and 41), and the kobold's sketch of the Kobold Caves (42).
- **The Journal now tracks your City Council quests.** Its Quests page lists old-city blocks you were asked to clear, proclamation quests once they are posted outside City Hall, and commissions from the clerk, Bishop Braccio, Cadorna, Lord Urslingen, and the council. Finished quests are marked DONE. The bottom line reads JOURNAL: ENTRIES QUESTS EXIT; Entries (E) returns to the Journal, while Escape or Exit closes it.
- **The Companion Tools map includes the Clue Book's labels.** In every area covered by the book, labels such as "Boat", "Temple of Tyr", and "Maze: Teleporters" appear on the same squares as they do on the printed map. Repeated labels appear everywhere they belong, but the page-specific key numbers are omitted. Keyed squares have light-cyan walls, and the Map tool shows the label under the cursor above your own note without replacing it. The legend now reads Dim: Not Visited and Yellow: Player Note. To hide the labels, turn off Clue Book Notes under Companion Tools in Settings.
- **F2 opens a new Bestiary** from the map, the wilderness, or camp. It records every creature you have met and what the party has learned: encounters and kills, size, armor class, hit dice, the hardest blow it has landed, and any attacks or defenses you have witnessed, including regeneration, poison, level drain, immunity to sleep, or reduced damage from blunt weapons. Unknown details appear as ??. The knowledge lives in BESTIARY.DAT rather than an individual saved game, so it carries across all your adventures.
- **The Slums' fortune teller can fill in your Bestiary.** If you spare her and later clear the Slums, she moves into a room beside the tavern on New Phlan's east edge. Before that, the room is bare; if you killed her, her crystal ball lies shattered on the floor. For 50 gold pieces per hit die, with a minimum fee of 100, she reveals a creature's size, hit dice, exact armor class, defenses, and attacks, then shows you the completed entry. Payment works as it does at a temple. She charges nothing when you already know everything she does, and she cannot help with a creature for which she has no record.
- **Spell lists now explain the highlighted spell.** Cast, Memorize, Scribe, Spells in Memory, the list shown when learning a spell at level-up, and a scroll's Use list all show its range, area or target count, duration, saving throw, and whether it is limited to camp or combat. The figures are calculated for the current caster, or at the scroll's level. Info (I) opens a full page with those details, casting time, and a description of how the spell works in this game. Next and Prev browse the other spells, and Exit returns to the same place in the list.
- **Magic items use the same spell-information pages.** From a character's Items screen, Info (I) explains an identified wand, potion, or other item that casts a spell, including the Potion of Speed, Keoghtum's Ointment, Javelin of Lightning, Dust of Disappearance, Necklace of Missiles, and Manual of Bodily Health. The page shows the range, area, duration, saving throw, when the item can be used, and what it does at the item's casting level. Next and Prev move among the character's other qualifying items. When you aim a Javelin of Lightning, the game also previews the bolt beyond its first target and everyone it will catch, just as it does for Lightning Bolt.
- **F7 opens a combat log.** It records attacks, hits, damage, misses, spells cast or lost, status effects, fallen characters, and guarding, grouped by round with the newest messages at the bottom. Use Up, Down, Page Up, Page Down, Home, and End to browse it. Combat Log in Settings turns the feature on or off, while Log Lines chooses a history of 10 to 60 messages (50 by default). The log requires EMS; without it, both settings are greyed out and Combat Log reads Needs EMS. The history lasts only for the current fight and is not saved.
- **Allow Gear Changes keeps Quick mode's hands off your weapons.** Characters fighting in Quick mode switch to whatever weapon and shield they rate best, so a ranger with a two-handed sword might take up his long bow at range and still hold it in the next fight. Turn Allow Gear Changes off, under Quick Mode in Settings or POOLCFG, and your characters keep what you readied; one holding a bow with an enemy beside it ends its turn instead of drawing a sword. It is on by default, as before, and NPCs and animated dead re-equip either way. Remember that Quick mode then won't reach for the silver or magic weapon that undead like wights call for.
- **Next and Prev aim at enemies.** When you aim an attack or an offensive spell, Next and Prev now step through the enemies only, as in Pools of Darkness, and the aim starts on your current target or the nearest enemy rather than on the attacker. A spell that is not an attack, such as Cure Light Wounds, steps through your own side instead. Manual and the cursor keys still reach anyone. Set Aim Cycles to All in Settings or POOLCFG for the old behaviour, every creature in turn.
- **Thrown weapons come back after the fight.** A hammer, axe, spear, javelin or other single thrown weapon no longer waits in the loot for you to take it: when the fight is won, it goes back to the character who threw it, readied again if that hand is free, with a message such as "Rex retrieves Hand Axe.". A character who can't carry it leaves it in the loot. Arrows, darts and other stacks are used up as before. Retrieve Thrown in Settings or POOLCFG turns this off; it is on by default.
- **A minimap of the whole battlefield.** Turn on Minimap (F3) on the Settings screen's Combat page (or in POOLCFG), or press F3 at the combat menu, and the bottom of the combat panel shows the entire arena, two pixels a square: walls in blue, your party in light cyan, enemies in yellow, the fallen in light red and the character whose turn it is in white. It is drawn while a character waits for orders, moves or aims, when the aim cursor shows on it in light magenta; an action's messages write over it until the next turn. On CGA, whose palette has no blue, only the creatures show. F3 turns it off again, and the setting remembers your choice. It is off by default. Idea from Joonas of Gold Box Companion.
- **A full-width combat view.** Turn on Wide View on the Settings screen's Combat page (or in POOLCFG) and the battlefield fills the top of the screen, 13 squares across and 6 down in place of 7 by 7, with the character whose turn it is (name, hit points, armor class and weapon) on one line under it and the fight's messages on the two lines below. It costs memory: a fight that can't spare it uses the usual view. The minimap has no room in it, so F3 says so instead. It is off by default. Idea from Joonas of Gold Box Companion.
- **The game offers to end a fight as soon as the last enemy falls.** As in Pools of Darkness, the round stops there, so your other characters no longer take turns with nothing to fight, and "Continue Battle:" comes up at once. Yes gives the party one more full round, after which the question comes again; No ends the fight.
- **Weapon sets: change weapons with one key in combat.** On a character's Items screen, press 1 or 2 on a weapon, shield, arrows or quarrels to put it in set 1 or set 2 (the same key again takes it out); the set's number shows at the right of the line. In combat, 1 or 2 readies that whole set, putting away what's in its way, so a fighter can switch between sword and shield and bow and arrows in one keystroke. It costs what readying through Use always has: nothing. The combat menu shows "1 2" when there's room, and F1 lists the keys. The idea comes from Joonas, author of Gold Box Companion.
- **Paladins can lead NPCs in combat.** As in Death Knights of Krynn and Pools of Darkness, at the start of each fight every paladin in the party tries to take command of each NPC fighting alongside it, such as Skullcrusher. The chance is 20% at paladin levels 1 to 3, 40% at 4 to 7 and 80% from 8, plus 5% for each point of Charisma above 13, so a 5th-level paladin with 17 Charisma succeeds 60% of the time. A window headed "Using leadership ability" names each success ("Galahad leads Skullcrusher."), and you then control that NPC for the fight; afterwards the computer takes it back. An NPC needs more than 3 Intelligence to follow.
- **The temples sell Heal, Resurrection and Restoration, and can repair the whole party.** As in Pools of Darkness, the Heal list now runs to twelve services, at the 1st-edition prices: Heal 5,000 gold pieces, Resurrection 11,000 and Restoration 7,000, which gives back one drained level. Repair, on the Heal screen's bottom line, adds up what everyone needs (each drained level, a raise or Stone to Flesh, and Heal for wounds), quotes one total ("Repairing the party will cost ... gold pieces."), takes it once and cures the party without further questions. Unlike Pools, the temple still charges, and Raise Dead and Stone to Flesh still make their survival and system shock rolls inside Repair; if a character does not survive, the priests put the price of what was left undone back in the pool. Repair leaves the animated dead alone, and a dead elf is named and skipped. The Temple of Bane's tenth off applies to all of it.
- **Restoration gives back the experience a level drain took.** Each level drained is remembered with the experience it cost, the hit points it took and the class it lowered. Restoration, from a temple, a scroll or Fix, gives back the most recent one first: that class's level, those hit points, and the lost experience added to what the character has earned since, so a character drained and restored ends up where it would have been. A level regained by training instead gives up the experience that drain took. Characters drained before this update are restored as before.
- **Animate Dead's dead join the party, as the manual promised.** After a fight the party wins, each creature a party cleric animated joins as an animated NPC under the computer's control, while the party has room ("THUG joins the party."). One with no room collapses as before ("... collapses; the party is full."). It joins before the treasure screen, so it can carry loot. Dispel Magic ending the spell no longer turns it against the party. The temple can raise one, but a raised one slips away while the party sleeps at its next rest, taking what it carries.
- **New Phlan has a magic shop.** The arms and armor shop at 11,12 now sells magic: a Javelin of Lightning (6,000 gold pieces), Potions of Extra Healing (1,600) and Speed (900), a Wand of Magic Missiles (40,000), 10 Darts +1 (150), 10 Arrows +1 (240), a Bag of Holding (50,000), and magic-user scrolls of three spells each, at 3,600, 7,200 and 10,800 gold pieces for first-, second- and third-level spells. Between them the twelve scrolls hold every magic-user spell of those levels, and choosing Buy on a scroll lists its spells and asks before you pay. The stock never runs out. New Phlan's other arms and armor shops, at 13,8, 8,11 and 8,13, sell what they always did.
- **The game says where to ask for help, and when DOSBox is too slow for it.** On its first start, and again after each new version, a screen before the main menu explains that this is a modified version of the game that GOG, Steam and SNEG can't help with, and asks you to send questions and bug reports to talonius@brazencrows.com. The same lines are on the Settings screen's System page and in the README. The DOS game also measures the computer's speed when it starts; when it runs slower than this version needs (DOSBox's default speed does), the screen also says to raise DOSBox's CPU cycles, `cycles=max` or for example `cycles=fixed 20000`, and it says so on every start until the speed is fixed. The System page shows the measurement as Speed Check, and under it, as Cycles, the DOSBox cycles it matches ("about 30,000"): DOSBox-X's fixed cycles, so under another DOSBox or on a real PC it is a comparison rather than the setting. The native versions show N/A.
- **Consolidate Coin trades your coins up.** Turn on Consolidate Coin on the Settings screen's Game page (or in POOLCFG) and whenever a character picks up coins, by Take, Share or selling, the purse is changed into the fewest coins of the same value: 5 gold pieces make a platinum, 1,000 copper make one too. Every coin weighs the same, so the load drops. It is off by default; coins handed from one character to another stay as they are.
- **Demihumans can pass their racial level limits.** Turn off Non-Human Level Cap on the Settings screen's Game page (or in POOLCFG) and dwarves, elves, gnomes, half-elves, halflings and half-orcs train as far as the experience table goes, as humans do, and the race screen at character creation shows U for every class the race can take. The game's own level limits for each class still apply, to every race. It is on by default, as in the rule book; a character already past its race's limit when you turn it back on keeps its levels and simply can't train further.
- **Every class can reach level 9, with the spells that go with it.** Turn off Game Level Cap on the Settings screen's Game page (or in POOLCFG) and clerics and magic-users train past 6, paladins and rangers past 7 and fighters past 8, all to 9, at the rule book's experience: a cleric needs 55,001 for 7th level, a magic-user 60,001. Spell slots now follow the real level (a 7th-level magic-user, Genheeris among them, has 7th level's), and clerics and magic-users gain 4th- and 5th-level spells, numbered as in Curse of the Azure Bonds: Cure Serious and Critical Wounds, Neutralize Poison, Protection From Evil 10' Radius, Sticks to Snakes, Dispel Evil, Flame Strike, Raise Dead and Slay Living for clerics (a 5th-level spell needs Wisdom 17), and Charm Monsters, Confusion, Dimension Door, Fear, Fire Shield, Fumble, Ice Storm, Minor Globe of Invulnerability, Remove Curse, Animate Dead, Cone of Cold, Feeblemind and Hold Monsters for magic-users. A 9th-level paladin casts a 1st-level cleric spell, and a ranger casts druid spells (Entangle, Faerie Fire, Invisibility to Animals and Detect Magic) from 8th level and a magic-user spell from 9th. A half-elf magic-user stops at 8, as the rule book has it, unless Non-Human Level Cap is off too. Game Level Cap is on by default, keeping SSI's limits; turning it back on lowers no one, it only stops further training.
- **Train anywhere, by the training hall's rules.** Turn on Train Anywhere (F4) on the Settings screen's Game page (or in POOLCFG) and F4 opens the training hall's menu wherever you are outside combat: on the map, in the wilderness or in camp. It offers Train, View and Dual Class, and Exit (or Escape) takes you back. Every rule of the hall still applies: training costs 1,000 gold pieces, needs the experience, gains one level at a time, and stops at the Game Level Cap and, while it is on, the Non-Human Level Cap; a change of class still costs 2,500. Training this way takes no game time. It is off by default, and with it off F4 does nothing; while it is on, the Command Keys window (F1) lists F4, closing up the blank lines between its groups when every key is listed so they all fit. Idea from Joonas, author of Gold Box Companion.
- **Magic-users can cast Cloudkill.** The last 5th-level magic-user spell lays a cloud of yellowish-green poison over nine squares, three by three around the square you aim at, within 2 squares, for a round per caster level. Any creature of up to 4 levels or hit dice in it dies; one of level 5 saves against poison at -4 and one of level 6 saves at no penalty, or dies; anything stronger is unharmed, as the 1st-edition rules have it, and walks through it. The cloud tries everyone in it when it appears, at the end of each round and on every step taken into it. Creatures immune to poison and the animated dead are unaffected. Monsters walk round it, as they do round a Stinking Cloud, and the aiming preview shows the cloud's squares before you cast.

- **The wilderness has a Move mode with diagonal steps.** As in Pools of Darkness, Move on the wilderness menu turns the bottom line to Exit. There the arrow keys move north, south, east and west, and Home, Page Up, End and Page Down (the keypad's 7, 9, 1 and 3) move diagonally, until Exit or Escape. A diagonal step takes 18 hours, against 12 for a straight one. The party can't squeeze diagonally between two impassable squares; one is no obstacle. The arrows still move from the usual menu, and Home and End there still pick the character.
- **Move mode shows more of the wilderness.** While you travel in Move mode the map fills the whole top of the screen, 13 squares across in place of 5, and the party list steps aside; the position and time sit on the bottom line in front of Exit. When something happens on the way (an encounter, a site's picture and question, a fight), the usual screen with the party list comes back for it, and the wide map returns at the next step. The help, Bestiary and items screens (F1, F2, Alt-1 to Alt-8) return to the wide map too. Exit or Escape gives back the usual screen.
- **The demo is back.** Leave the main menu alone for thirty seconds with no party and it plays the demo the Commodore 64 release had, from the C64's own script: its six captions, a walk through Podol Plaza, an ogre in the 3D view and up close, and a battle against orcs and the ogre fought by four pre-made adventurers (RESTAL, TARRAN, DIANE and WILLIAM D'OR). Any key ends it at once, mid-walk or mid-battle, and returns you to the main menu as it was: the demo saves nothing, earns no experience or treasure and teaches the Bestiary nothing, and a character created next rolls as it would have without it. The demo lives in DEMO.DAX, a new file of this release; without it there is no demo. Starting the game with `DEMO` plays it after three seconds.
- **Shops have a new Buy screen.** Buy now opens a full screen with tabs along the top: All, Melee, Ranged, Armor, Ammo and Misc (keys L, M, R, A, O and I). The stock scrolls a line at a time as you move through it, with a scroll bar beside it when the list is longer than the screen, instead of Next and Prev pages. The bottom line says Showing All or Showing Usable, and S switches between them: Showing Usable lists only what the selected character's class can use; an empty list reads "** NO ITEMS **". Under the list are the character's gold and the pool's, the character's armor class and damage now (Curr) and with the highlighted item readied (New), and the armor, shield, weapon and ammunition it has readied. The shield turns red when the highlighted weapon needs both hands. An item the character can't use, or can't ready past a cursed item, shows "--", and so does ammunition the readied weapon doesn't shoot; a scroll, potion or other item no one readies leaves the figures as they are. Buy (B) or Enter buys the highlighted item as before. Alt-1 to Alt-8 make another party member the buyer, keeping the highlight on the same item when it is still listed. F1 lists the screen's keys.
- **F1 on the Items screen lists its keys.** Ready, Use, Trade, Drop or Deposit, Halve, Join, Sell and Id, the weapon-set keys 1 and 2 (set or unset the highlighted weapon or shield), and Alt-1 to Alt-8 to switch to another character's items.

### Interface improvements

Most of these changes are small on their own, but together they make the game easier to understand and harder to operate by accident.

- Menus mark the highlighted choice in inverse video, black on the highlight colour, as the later Gold Box games do, in place of a change of text colour. That covers every bottom-line menu (the map, camp, shop and Yes/No prompts among them), every list (Items, spells, shop stock, the roster), the training hall's party menu, the Load/Save slots (the slot's letter), the Journal, the Bestiary, the rest timer, the Dual Class and Levels screens, and the Settings screen, where the highlighted setting's chosen value is the one marked. The inverse covers the whole choice, from the start of the word holding its hotkey, so coMbat and sYstem light their words alone (#1197) and a choice of several words lights every one of them: ADVANCE CAUTIOUSLY, and PRESS <ENTER>/<RETURN> TO CONTINUE, which lit only PRESS (#1216).
- POOLCFG takes Borland's colours, in homage to the Turbo Pascal it was first written in: yellow text on the deep blue, and grey menus with black text and red keys. On Linux and macOS, in a terminal with 24-bit colour, it shows the VGA's own blue and the rest rather than the terminal's palette's.
- In the Linux, Windows and macOS versions, Command-Q, the app menu's Quit, the window's close button and Alt-F4 now ask "Quit Pool of Radiance? Progress since your last save will be lost." before ending the game, with Quit and Cancel; Return and Escape choose Cancel. On a Mac the game's Alt is Option, so Option-Q is Quick: reaching for Alt-Q no longer loses your game. The macOS README says so.
- On the Load/Save menu, Quit now just asks "Exit to DOS?", without offering to save first, and X chooses Exit.
- On the Load/Save menu, Q now chooses Quit. The quick save (F5 and F8) has moved from slot Q to slot Z to make room: the first time you start the game after this update, a quick save you already have moves to slot Z, with its characters and vault.
- At the vault's counter the Up and Down arrows now step through the party, as they do at the shop's.
- The menu for taking coins from the treasure now lists them as a character's coin menus do, jewelry first, with the names lined up.
- Cast on the map for a character who cannot cast now says why, as it does in the wilderness and in camp, instead of doing nothing.
- A character's items menu now offers only what you can do with the highlighted item: Halve on a stack of two or more and Join when another stack can join it. The menu no longer runs off the bottom line in a shop.
- In a shop or temple, Id is offered on every item again, as in SSI's game, so the menu no longer tells you which items are magic; identifying an ordinary item still costs 200 gold pieces. Info pages for magic items are available away from the counter.
- When you change a character's portrait from camp, Escape now leaves the portrait picker and keeps the portrait the character had.
- A character's More Info screen now has its own menu: Saves, Stats, Kills, Thief (for characters with thief levels, single or multi-class) and Exit. Stats and Kills show the game statistics and the kill count on the More Info screen itself, without a menu of their own; on the kill count, the Up and Down arrows scroll a row and Page Up and Page Down a page. Thief shows each thief skill with its racial, Dexterity and level parts and the total.
- A character who can turn undead (a cleric, or a paladin of 3rd level or more) has a Cleric page on the More Info screen, Cler (C) on its menu, now headed INFO: so that Thief and Cler fit together. It shows the level the character turns undead at and, for each kind of undead from skeleton to vampire, what turning does at that level: D destroys it automatically, T turns it automatically, a number is the least roll on a d20 that works, and a dash means the character cannot turn it yet. The figures are the ones combat uses.
- The Companion Tools (F6, when turned on in Settings) open straight onto the area's map. Map and Notes are now one tool: Map puts a cursor on the map to write and clear your notes on squares. The map also draws much faster in areas with many event squares, such as the Temple of Bane.
- The Settings screen now has pages, chosen on the bottom line: Game, Sound, Camp, Combat and System. Each setting can now be turned off on its own: monster and character portraits under Portraits, the title and battle music under Music, and under Sound the footsteps, ranged weapons, melee attacks, the death scream and walking into a wall. System shows the video and sound device, the game, data and memory details, and whether the overlays are in EMS.
- The Paths page is gone, from the Settings screen and from POOLCFG: the places it kept for the later games' folders were for sharing graphics between the games, which waits for later work. POOLCFG's Hardware page now holds Pool of Radiance's own Data Path and Save Path, edited and checked as before. A POOLOPT.CFG that still has the later games' folders keeps them, unread.
- Combat settings have a page of their own. - A cleric or magic-user drained to 1st level now has 1st level's spell slots, and loses memorized spells it no longer has slots for. Before, it kept 2nd level's slots.
- A half-orc cleric or thief now stops at the rule book's racial level limit: a cleric at 4 to 7 by Wisdom, a thief at 8 to 11 by Dexterity. Before, half-orcs had no limit.
- The Companion Tools' character editor no longer holds a character above level 1 to fewer hit points than its Constitution gives it: the bonus now counts on every hit die, not once a class.
- The spell page's descriptions of Curse and Sleep now match the spells: Curse affects foes already in melee, and Sleep never affects a level-5 creature that is not a monster.
- Friends no longer leaves a lasting Charisma bonus when cast twice.
- Every cure of disease now works the same way, and the temple's and a paladin's Cure Disease no longer end the nausea of a Stinking Cloud.
- A setting changed before your first save now sticks: the game makes the save folder (and, in the Linux, Windows and macOS versions, your own folder above it) before writing the settings, as a save does. Before, the settings were lost while the save folder was not there yet. POOLCFG makes a missing save folder the same way.
- A dual-classed character can now be removed from the party and saved on her own. Before, the game said "Could not save" and kept her in the party. While it writes a file, the game now keeps its working copies in a TMP folder beside the file (SAVE\TMP, for example) instead of beside it under a name ending in $ or %. Because of that folder, a DOS data or save folder's path can be up to 59 characters long, down from 67.
- A dead or unconscious Skullcrusher now leaves the party outside City Hall, as a standing one does: "Cadorna's personal guard cart the fallen Skullcrusher away." Before, he stayed in the party for good.
- The game no longer leaves files such as BODY.$$$ in its folder: it builds its combined data files in the same TMP folder, and removes any such files an earlier version left.
- A quick save moved from slot Q to slot Z keeps all its characters and its vault, even when the game was closed during the move and the move had to run again at the next start.
- A save made after midnight, in a game started the day before, now shows the new date on the Load/Save menu in DOSBox-X. Before, it showed the day the game was started.

## Pool of Radiance port: October 2026 update

This update to the Pool of Radiance port (SSI's 1988 game, version 1.3, rebuilt from its source) collects a week of work from 10 to 17 October 2026. It adds paladins and rangers at character creation, a settings screen, a full-screen load and save menu with quick save and quick load, a vault in New Phlan, and statistics for each character. The rules now run to an ability score of 25, a long list of bugs from SSI's original is fixed, and the combat AI no longer runs in circles. Behind the scenes the code has been restructured and put under automated tests, and the game gains a VGA mode and can load its overlays from expanded memory. Your existing saved games and characters still load.

Here is what that means in play.

### New features

- You can now create paladins and rangers. Humans can be either; half-elves can be rangers or cleric/rangers. The usual party rules apply when adding them: a paladin will not join a party with an evil member (nor an evil character a party with a paladin), and a party may have at most three rangers. The race screen shows the new classes and their level limits.
- A new Settings screen, reached from the start menu (Game Settings) and from Alter during play, gathers game speed, monster pictures, portraits, music, sound, Auto End Quick Mode and the starting state of Quick Mode Magic in one list. Settings are now kept for all your games in POOLOPT.CFG rather than in each saved game. The screen also shows your video and sound setup, the game and data versions, and free memory.
- Loading and saving now use a full-screen menu that shows each slot's description, the area it was saved in, and the date and time. Press a slot's letter to load or save it at once. When saving you can type a description of up to 27 characters; left empty, it reads SAVE GAME and the slot's letter.
- Quick save and quick load: on the map, press F5 to save to a dedicated quick-save slot and F8 to load it. The quick save also appears on the load and save menu.
- The Hoarder's Respite, a vault in New Phlan in the building that was a tavern at (8,9), as in Secret of the Silver Blades. You can deposit money and up to 100 items there and take them out later. The vault is saved with each saved game.
- Each character now keeps statistics: kills (by type of creature), damage dealt and taken, healing given and received, times raised, poisoned, knocked down and killed, spells cast, items looted, and coins looted (net of pooling and sharing). The game keeps party totals too. Find them on the character's More Info page under Stats, which has a Game page and an alphabetical Kills page.
- A paladin's Heal and Cure now appear directly on the View menu instead of being hidden under More. More Info (the saving throws and the statistics) is opened with M, shown under the portrait.
- When you choose Exit to DOS with unsaved changes you are asked whether to save first, and you can now quit without saving. This also works in the training hall.
- When the party is destroyed you now return to the main menu instead of being dropped to DOS.
- If the game runs out of memory it now offers to save before quitting: press Enter to save, or Escape to quit.
- When choosing who will fight a duel (the training hall arena, the buccaneer in the Pitt, the Lizardman Keep's champion), you can now press Escape to change your mind.
- Journal entries that run over several pages show "(more)" at the top or bottom of the page.
- For testers, the STING debug mode gains Curse of the Azure Bonds' tools: a script trace log, a dump of creature effects, a raw item viewer, automapping anywhere, a free-training toggle, and a memory display.

### Gameplay changes

- Ability scores now run all the way to 25, using the Deities & Demigods tables above 18. High Constitution gives a larger hit-point bonus, raises the lowest possible roll on each hit die, improves saves against poison, and speeds up regeneration. High Dexterity improves thief skills, and high Wisdom gives clerics more bonus spells.
- Multi-class characters with a fighter, paladin or ranger class now get the warrior's Constitution hit-point bonus for that class, as the rules intend.
- Clerics, and multi-class characters with a cleric class, can no longer be created true neutral, as the rules require. Existing characters keep their alignment.
- Ability scores can no longer fall below 3 or rise above 25 during play. Raise Dead, for example, can no longer reduce Constitution below 3.
- The Manual of Bodily Health now always raises your hit points as well as your Constitution, and reading a second one no longer stacks extra regeneration.
- Keoghtom's Ointment now revives only a character killed by poison, not one who was poisoned and then died of wounds.
- Party members fighting under Quick Mode now bandage dying teammates, as in Curse of the Azure Bonds.
- When the surprise roll succeeds for both sides, both sides are now surprised.
- Robbers' chances of stealing heavy items no longer protect the items after them in your pack.
- A randomly generated javelin is now sometimes a Javelin of Lightning, instead of a nameless broken item.
- Characters without magic-user levels are now told that scribing a scroll requires arcane training.
- Camp's Fix now tells you why it cannot help: no clerics, no cleric able to cast, nothing left to heal, or no spells left to heal with.

### Fixes

- Fixed a bug where a character hit while casting kept the spell and the attacker lost it instead.
- Fixed monsters and Quick Mode characters losing an extra copy of a spell when caught in their own spell's area.
- Fixed monsters and Quick Mode characters sometimes dropping a spell they had begun casting in order to use an item.
- Fixed the combat AI running back and forth against walls and dead ends; creatures now find their way around walls and other bodies to reach their target.
- Fixed Share handing out more money than the pool held when a hired NPC was in the party.
- Fixed Restoration never appearing in the spell book.
- Fixed pressing 2 or - during the computer's combat turns toggling quick magic or triggering a debug cheat.
- Fixed Space in combat treating animated creatures differently depending on whose turn it was.
- Fixed fleeing monsters running diagonally when the party faced north or south.
- Fixed removing the Gauntlets of Ogre Power sometimes removing the wrong Strength effect.
- Fixed joining a readied stack of items (arrows, for example) into an unreadied one losing its Ready status.
- Fixed the temple's "you left some money here" prompt erasing the priest's words before you could read them.
- Fixed the message when dropping an item: "Your Long Sword will be gone forever" now has exactly one space.
- Fixed the missing space in the buccaneer's challenge in Podal Plaza: "WHO WILL IT BE?' WHAT DO YOU DO?".
- Fixed a stray letter at the end of Camp's Rest menu ("EXITT").
- Fixed missing full stops in Camp's scribe and drop messages, and the misspelling "scibing".
- Fixed the last picture shown (often the treasure after a fight) appearing over the 3D view after saving.
- Fixed camp showing a black view behind the "Quit to DOS?" question after saving.
- Fixed the rest timer showing 24 or more hours during long memorizing rests.
- Fixed a newly loaded game sometimes running an old copy of the area's script; the area's script is now always loaded fresh, so data fixes take effect in older saves.
- Fixed a quick load sometimes starting by itself on the first step after starting the game.
- Fixed fatal error messages being wiped from the screen and leaving DOS in graphics mode.
- Fixed text in CGA mode changing colour partway through repeated letters.
- Fixed a wrong picture (or none) sometimes appearing after the game changed disks.
- Fixed a write-protected usual-spells file being treated as missing.
- Fixed a missing data file producing an unhelpful "Insert disk" prompt; the game now names the file it could not find and the right drive.
- Fixed the game stopping at start-up when the Brazen Crows title picture (RAVFULL.DAX) is not present; it is now skipped.
- Fixed many rare crashes and hangs that damaged saves or unusual situations could cause, found by a review of the whole source.

### Interface improvements

- The arrow keys now step through your characters on every menu where Home and End do, including the start menu and camp, and move characters in Party Order.
- The combat icon editor now has Keep and Exit: Keep accepts your design, Exit discards your changes. E works as Exit's key, the character's name is shown in cyan, and long lists show "(more)".
- The portrait picker's Okay is now Keep.
- Under Quick Mode, the bottom line shows how to leave it (Space) and whether Quick Mode Magic is on (Alt-M).
- The message when an aligned weapon shocks its wielder now shows the weapon and character in green and the rest in white, so it is easier to read.
- The start menu's title now shows the game's version.

### Under the hood

- The source has been reorganised: shared code has been gathered into common routines, tangled dependencies between parts of the program removed, and many magic numbers given names. The game uses its memory more carefully as a result, with more free memory and fewer disk loads during combat.
- The port is now covered by automated tests: unit tests of the rules, and recorded play-throughs replayed against earlier builds in every video mode to catch any change in behaviour. Saved games and character files are checked against SSI's original formats.
- Saved games no longer contain stray memory contents, so the same game always saves to the same file.
- A new VGA video mode is available (choose V for video in POOL.CFG), alongside CGA, EGA and Tandy. The video code has been rebuilt around one driver per mode.
- The game loads its overlays from expanded memory (EMS) when enough is available, which avoids reading them from disk during play, and the second wilderness tile set is now loaded only when needed.
- The script area has room for longer area scripts, so future data fixes are easier to make. Saved games keep their original size and layout.
